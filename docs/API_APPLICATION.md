Creating a repository does not guarantee API approval.

## Suggested application summary

I am developing a local Python tool to organize my personal movie, TV show, and anime library. The initial prototype searches TMDB metadata and retrieves season episode lists. I plan to use titles, release years, season numbers, and episode numbers to generate reviewed, standardized filenames for my private media library.

This project is for private, non-commercial use only. It will not distribute video files or resell TMDB data. I will comply with TMDB's API terms and attribution requirements.

## Data use and privacy

- Queries are made directly to TMDB's API.
- The tool sends search terms and selected TMDB IDs, not local video content.
- Credentials are supplied interactively or through an existing environment variable.
- No real media inventory, account credentials, or private file paths are included in this repository.
- A graphical interface, image display, and batch file renaming are not part of the current prototype.
